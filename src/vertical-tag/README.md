# 竖排价签模块（vertical-tag）

货架侧边竖贴价签的排版与矢量预览。价签上只排三个字：**Ç、Ć、Č**，
使用同一套试验字最重的一档（wght 900），从上往下竖排。

## 试验字模型（`experimental-font.js`）

- 只有一条字重轴 `wght`：范围 **200–900**，默认（不拉轴）停在 **200**。
- 字符集只有 `Ç`(U+00C7)、`Ć`(U+0106)、`Č`(U+010C)。
- 每个字在 200 / 900 两个主控各有一条路径，命令骨架完全一致、坐标不同，
  中间字重按线性插值得到——所以这是一条真正可插值的可变字体数据。

| 字重 | hAdv（字宽） | vAdv（竖向前进） | 路径开头 |
| ---- | ------------ | ---------------- | -------- |
| 200（默认） | 562 | Ç=1000（Ć/Č 同为 1000，做对比用） | `M328 -12` |
| 900（最重） | **586（三字相同）** | Ç=**962**，Ć=**1058**，Č=**1014** | `M354 -12` |

900 档的三条路径开头都是 `M354 -12`，与 200 档的 `M328 -12` 不是同一条路径；
把字重拉回 200，Ç 的 vAdv 回到 1000、路径开头回到 `M328 -12`。

## 竖排规则（`layout.js`）

- 每个字的横向位置恒为 `x = 0`，三个字**左对齐**，不会一个比一个往右错。
- 竖向起点按每个字自己的 **vAdv 累加**，字宽 hAdv（586）只决定标签横向
  宽度，**不是往下走的步长**：

| 字重 900 | 第 1 字 Ç | 第 2 字 Ć | 第 3 字 Č | 总长 |
| -------- | --------- | --------- | --------- | ---- |
| 竖向起点 y | **0** | **962** | **2020** | **3034** |
| vAdv | 962 | 1058 | 1014 | — |

其中 `2020 = 962 + 1058`，不是 `962 × 2`；Č 的 1014 只计入总长，不当第二字的步长。
标签高度按 3034 裁切。

切回 200 档时，vAdv 全部回到 1000，起点随之变成 `0、1000、2000`，
第二字不会残留 962。

模块同时提供两种等价排法：

- `layoutVertical()`：直接按 vAdv 往下排（默认，字形直立）。
- `layoutRotated()`：先沿横排方向按 vAdv 排完，再把整列顺时针旋转 90°。
  路径命令本身不改写，所以三条路径开头仍是 `M354 -12`，起点仍是
  `0、962、2020`，总长仍是 3034（字形侧躺）。

## 矢量预览（`render.js` / `preview/`）

- `renderPriceTag(chars, { wght, rotated, ruler })` 输出 SVG 字符串。
  字体坐标 y 向上、SVG 坐标 y 向下，每个字套 `scale(1,-1)` 并平移到其
  竖向起点，因此在 SVG 里直接量第二个字的左上角就是 **y=962**。
  每个字形组带 `data-x / data-y / data-vadv / data-hadv`，标尺上也直接
  标出 `第2字 y=962` 等读数。
- `preview/vertical-tag.html`：交互预览，拖动 wght 滑块（200–900）时
  起点随 vAdv 实时联动，右侧表格与核对清单实时更新；可切换旋转方案。
  页面通过 ESM 相对路径导入，需用本地静态服务器打开，例如：

  ```bash
  python3 -m http.server
  # 浏览器访问 http://localhost:8000/preview/vertical-tag.html
  ```
- `node preview/vertical-tag-export.mjs`：静态导出
  `price-tag-w900.svg`（交付稿）、`price-tag-w200.svg`（对比稿）、
  `price-tag-w900-rotated.svg`（旋转等价稿）。

## 测试

`test/vertical-tag.js` 钉死全部硬指标：轴范围与默认值、两档度量与路径开头、
起点 0/962/2020、总长 3034、左对齐、200 档回退、中间字重插值、旋转等价性，
以及 SVG 中画出的轮廓必须与按字符取到的路径完全一致。

```bash
npx mocha test/vertical-tag.js
```
